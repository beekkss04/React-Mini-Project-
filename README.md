# 📌 Project Management Tool

Deployed Link :- https://projectflow-react.netlify.app/

A modern **React.js mini project** for organizing tasks, setting priorities, assigning members, and tracking deadlines with an intuitive drag-and-drop interface.

---

## 🚀 Overview

The **Project Management Tool** is a productivity-focused web application designed to help teams manage projects efficiently.
It allows users to create tasks, assign priorities, monitor progress, and collaborate through comments and attachments.

This mini project demonstrates practical implementation of:

* React.js component architecture
* State management
* Drag-and-drop functionality
* Responsive UI design
* Task workflow management

---

# ✨ Features

### ✅ Core Features

* 📋 Drag-and-drop task boards
* 🔥 Task priority levels
* 👥 Member assignment system
* ⏰ Deadline alerts
* 📊 Project progress tracking
* 💬 Task comments & attachments
* 📅 Calendar view of tasks
* 📁 Multiple project support

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/project-management-tool.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd project-management-tool
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm start
```

The application will run on:

```bash
http://localhost:3000
```
